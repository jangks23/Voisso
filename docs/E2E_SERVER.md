# 서버 E2E 검증 결과

> `python3 -m server.e2e_check` 가 자동 생성한다. 손으로 고치지 마라.
> 브라우저를 쓰지 않는다 — **HTTP 로만** 서버를 검증한다.

- 측정 시각: 2026-08-22T01:38:37Z
- 대상 서버: `http://127.0.0.1:8000`
- 입력 경로: 오디오(WAV)
- 결과: **전부 통과**

## 1. 통화 왕복

`POST /api/call/start` → `turn` ×4 → `POST /api/call/end` 를 HTTP 로 실행했다.

| 턴 | 어르신 발화 | 응답 | 오디오 |
|---|---|---|---|
| 1 | 아 저기 집 앞에 물이 안 빠지고 자꾸 고여서 큰일이라예 | 아이고, 집 앞에 물이 계속 고이는네예. 물이 빠지지 않는 문제로 접수해 드리면 될까예? | O |
| 2 | 안동시 옥동입니더 | 네, 안동시 옥동이네예. 어떤 문제가 생겼는지 말씀해 주이소. | O |
| 3 | 장마철부터 그랬어예 | 네, 장마철부터 물이 고였네예. 연락받으실 전화번호를 말씀해 주이소. | O |
| 4 | 010-1234-5678 이라예 | 네, 전화번호 확인했습니더. 집 앞에 물이 고이는 문제로 접수해 두었고, 담당하는 곳에서 연락드릴 겁니더. | O |

## 2. 구간별 지연

턴 하나가 처리되는 동안 각 구간이 실제로 쓴 시간(ms)이다.
서버가 응답 `meta.timings` 에 실어 보내는 값을 그대로 옮겼다.
`왕복(HTTP)` 은 클라이언트가 잰 전체 왕복 시간이다.

| 턴  |       stt | normalize |       llm |   dialect |       tts |     total | 왕복(HTTP) |
|----|-----------|-----------|-----------|-----------|-----------|-----------|------------|
|  1 |       948 |        14 |      2446 |         0 |      1435 |      4842 |       4847 |
|  2 |       711 |         0 |      2396 |         0 |      1257 |      4365 |       4368 |
|  3 |       800 |         0 |      2367 |         0 |      1548 |      4715 |       4718 |
|  4 |      1035 |         0 |      1946 |         0 |      1854 |      4834 |       4839 |

통화 종료(`POST /api/call/end`)는 턴과 구간 구성이 달라 따로 적는다.
요약 LLM 한 번과 부서 라우팅이 전부다.

| 구간 | 소요 |
|---|---|
| 요약 생성 (LLM) | 1222ms |
| 부서 라우팅 + 카드 생성 | 74ms |

### 병목

- **LLM**: 평균 2288ms (최소 1946 / 최대 2446)
- **TTS**: 평균 1523ms (최소 1257 / 최대 1854)
- **STT**: 평균 874ms (최소 711 / 최대 1035)

### 스트리밍 TTS

계약서의 `audio_b64` 는 통짜 오디오라 합성이 끝나야 첫 소리가 난다.
`POST /api/tts/stream` 은 청크를 흘려보내므로 첫 음성이 훨씬 빨리 시작된다.

| 방식 | 첫 음성까지 | 전체 |
|---|---|---|
| 통짜 합성 (`audio_b64`) | 1548ms | 1548ms |
| 스트리밍 (`/api/tts/stream`) | **702ms** | 854ms |

첫 음성까지 **846ms 단축**된다 (1548ms → 702ms). 통화 데모에서 체감이 가장 큰 구간이다.

## 4. 키 없는 텍스트 모드

API 키를 하나도 주지 않고 띄운 서버(`http://127.0.0.1:8002`)에 **같은 HTTP 경로**로
같은 통화를 걸었다. 심사자가 키 없이 저장소만 받아 실행하는 경우다.

| 항목 | 값 |
|---|---|
| 대화 엔진 | rule |
| 음성 인식 | none |
| 음성 출력 | none |
| 턴당 왕복 | 2~41ms |
| 민원카드 | `0021` — 안동시 옥동, 아 저기 집 앞에 물이 안 빠지고 자꾸 고여서 큰일이에요 (장마철부터) |
| 배정 | 기후환경국 맑은물정책과 |

외부 API 를 하나도 부르지 않으므로 턴당 응답이 밀리초 단위다.
대화는 규칙 기반이라 단조롭지만 **슬롯 채우기 → 부서 배정 → 민원카드까지
전 구간이 동일하게 동작한다.**

## 재현

```bash
python3 -m server                  # 서버 기동
python3 -m server.e2e_check        # 이 보고서를 다시 생성
python3 -m server.e2e_check --text-only   # 오디오 없이 텍스트 경로만

# 키 없는 서버를 따로 띄워 같은 보고서에 담기
env VOISSO_AGENT_PROVIDER=rule VOISSO_TTS_PROVIDER=none VOISSO_STT_PROVIDER=none \
    OPENAI_API_KEY= ANTHROPIC_API_KEY= TYPECAST_API_KEY= \
  python3 -m server --port 8002 &
python3 -m server.e2e_check --keyless-base http://127.0.0.1:8002
```

합성한 WAV 는 `.cache/e2e_audio/` 에 캐시된다. `--fresh` 로 무시할 수 있다.
