# Voisso 데모 대본 (촬영 · 시연용)

> **목표 길이 2분 30초.** 4단계 + MCP 마무리.
> 각 단계는 심사 기준 하나씩을 증명한다. 설명하지 말고 **보여준 다음** 한 줄로 못박는다.
>
> ⚠️ 이 문서의 대본은 **현재 동작하는 기능**만 담았다. 아직 작업 중인 것은 `[예정]` 으로 표시했다.
> 촬영 시점에 완성되지 않았다면 그 컷은 빼고 간다. 없는 걸 있는 척하면 심사에서 더 크게 잃는다.

## 0. 문제 제기 — 0:00–0:15 ⏱ 15초

**첫 15초가 전부다.** 아키텍처 다이어그램으로 시작하지 마라. 문제를 던지고 곧바로 사투리를 들려준다.

| | |
|---|---|
| **화면** | 검은 배경에 흰 텍스트 두 줄. 그다음 **바로** 통화 화면으로 컷 전환. |
| **자막** | `경상북도, 65세 이상 인구 비율 전국 최상위권` → `민원 창구는 여전히 ARS입니다` |

**내레이션**

> "경북 어르신이 도청에 전화를 겁니다. 1번 도로, 2번 상하수도, 3번… 끝까지 듣고 자기 민원이 몇 번인지 골라야 합니다. 잘못 누르면 처음부터. 그리고 그 다음 안내는, 표준어로만 나옵니다."

**연출 주의**
- 이 15초 동안 Voisso가 무엇인지 **설명하지 않는다.** 문제만 던진다.
- 0:15에 곧바로 어르신 목소리가 나와야 한다. 정적을 두지 마라.

## 1. 사투리 → STT 오인식 → 정규화 교정 — 0:15–0:50 ⏱ 35초

**증명 대상: 혁신성 및 차별성 (20%)**

| | |
|---|---|
| **화면** | `web/call/index.html` 통화 화면. 발화 → STT 원문 → 정규화 결과가 순서대로 뜬다. |
| **핵심 컷** | STT 원문과 정규화 결과가 **동시에 보이는 순간.** 여기서 1초 멈춘다. |

**입력 문장** (실측 검증된 예시)

```
어르신 발화 :  비가 오면 집앞 도로에 물이 안 빠져가 큰일이라예
정규화 결과 :  비가 오면 집앞 도로에 물이 안 빠져서 큰일이에요
```

**내레이션**

> "'물이 안 빠져가 큰일이라예.' 음성인식은 이걸 그대로 받아씁니다. 표준어 기준으로 학습된 모델이니까요. Voisso는 여기에 방언 레이어를 하나 더 둡니다. 경북 방언 어휘 367개와 어미 규칙 70개로 표준어로 되돌린 다음, 그 결과를 AI에게 넘깁니다."

**못박는 한 줄**

> "어르신이 말을 고치는 게 아니라, 시스템이 알아듣습니다."

**연출 주의**
- 화면에 **원문과 교정문을 나란히** 띄워라. 이 대비가 이 컷의 전부다.
- `-가` → `-서`, `-라예` → `-이에요` 처럼 **바뀐 부분에 하이라이트**를 넣으면 좋다.
- 음성 입력이 준비되지 않았다면 **텍스트 입력으로 진행한다.** 문장이 같으면 메시지는 동일하다.

## 2. AI가 사투리로 되물으며 슬롯을 채움 — 0:50–1:25 ⏱ 35초

**증명 대상: 기술적 완성도 (25%)**

| | |
|---|---|
| **화면** | 통화 화면 우측 슬롯 패널. 4개 항목이 차례로 채워진다. |
| **슬롯** | `무슨 일` · `어디서` · `언제부터` · `연락처` |

**대화 흐름**

```
AI    :  어데신지 여쭤봐도 될까예?          ← 표준어 응답을 경북 사투리로 변환해 출력
어르신:  안동 옥동인데예
AI    :  언제부터 그랬는교?
어르신:  장마 지나고부터 계속 그래예
```

**내레이션**

> "AI는 사투리로 되묻습니다. 무슨 일인지, 어디인지, 언제부터인지, 연락처. 네 가지가 채워지면 통화를 마무리합니다. 한 항목은 최대 두 번까지만 묻고, 그래도 안 나오면 넘어갑니다. 어르신을 심문하지 않기 위해서입니다."

**못박는 한 줄**

> "버튼을 누를 필요가 없습니다. 그냥 말하면 됩니다."

**연출 주의**
- 슬롯이 **하나씩 체크되는 애니메이션**이 이 컷의 시각적 핵심이다. 패널이 화면에 반드시 들어오게 프레이밍하라.
- 되묻는 문장이 사투리로 나온다는 점을 자막으로 강조하라 (`될까요?` → **`될까예?`**).

## 3. 통화 종료 → 민원카드 → 사무분장 원문 근거 — 1:25–1:55 ⏱ 30초

**증명 대상: 공공데이터 실사용 (필수 조건) · 공공부문 활용 가능성**

이 컷이 **이 프로젝트에서 가장 중요하다.** 여기서 공공데이터를 실제로 쓴다는 걸 증명한다.

| | |
|---|---|
| **화면** | 통화 종료 → 민원카드 생성. 카드의 `배정 근거` 인용 블록을 **확대**한다. |

**화면에 뜨는 값** (실측)

```
요약   : 안동 옥동 주택가 배수 불량, 강우 시 반복
배정   : 기후환경국 맑은물정책과 (주무관)   ← 확신도 낮음: 후보 3곳 함께 제시
근거   : ◦ 하수도 재난재해대책(호우, 태풍 등) 수립 및 시행 …
대안   : 농축산유통국 스마트농업혁신과 (0.586) — 근거: 배수개선사업
```

> **"확신 없음"이 뜨는 건 사고가 아니다.** 배수 불량은 하수도 소관일 수도, 농업기반
> 정비 소관일 수도 있다. 억지로 하나를 고르지 않고 근거와 함께 후보를 내미는 것이
> 설계 의도다. **내레이션에서 이걸 약점처럼 말하지 마라.**

**내레이션**

> "통화가 끝나면 민원카드가 만들어집니다. 여기서 중요한 건 맨 아래 '근거' 한 줄입니다. 이건 AI가 지어낸 설명이 아니라, **경상북도청이 공개한 그 부서의 사무분장 원문**입니다. 저희는 도청 조직도에서 96개 부서, 1,866건의 담당업무를 수집해 라우팅 근거로 씁니다."

**못박는 한 줄**

> "AI가 그렇게 판단했다, 로 끝나지 않습니다. 왜 그 부서인지가 공공데이터 원문으로 남습니다."

**연출 주의**
- `근거` 블록을 **화면 가득 확대**하라. 이 한 줄이 심사 기준 두 개(공공데이터 실사용 + 공공부문 활용 가능성)를 동시에 친다.
- 확신도가 낮을 때 **후보를 여러 개 제시**하는 화면이 있다면 0.5초라도 스쳐라. "단정하지 않는다"는 신뢰 요소다.

## 4. 담당자 대시보드에 실시간 도착 — 1:55–2:15 ⏱ 20초

**증명 대상: 공공부문 활용 가능성 (25%)**

| | |
|---|---|
| **화면** | 좌: 통화 화면 / 우: `web/dashboard/index.html`. **분할 화면**으로 둘을 함께 보여준다. |

**내레이션**

> "같은 시각, 담당 공무원 화면입니다. 방금 그 민원이 부서에 배정되어 올라옵니다. 담당자가 가장 먼저 보는 것도 그 근거 문장입니다. 왜 나한테 왔는지 한 줄로 확인하고, 아니면 바로 재배정합니다."

**못박는 한 줄**

> "잘못 배정된 민원이 부서를 떠도는 일을 줄입니다."

**연출 주의**
- 분할 화면이 이 컷의 전부다. 통화 종료 → 대시보드 등장이 **끊김 없이** 이어져야 한다.
- `[예정]` **실서버 연동**: 현재 대시보드는 샘플 데이터로 동작한다. `server/` 완성 전이라면
  통화 화면과 대시보드를 **각각** 보여주고, 내레이션에서 "실시간"이라는 단어를 빼라.
  대신 "담당자는 이 화면으로 받습니다" 로 바꾼다. **없는 연동을 있다고 말하지 마라.**

## 촬영 체크리스트

시연 **30분 전**에 순서대로 확인한다.

### ⚡ 원터치 실행

```bash
./scripts/demo.sh                # 데이터 준비 → 서버 기동 → 브라우저 열기
./scripts/demo.sh --no-browser   # 브라우저를 직접 배치하고 싶을 때
./scripts/test.sh                # 지금 무엇이 동작하는지 한눈에 (없는 키는 SKIP)
```

**둘 다 완성되어 동작한다.** `demo.sh` 는 7단계를 밟으며 무엇을 하는지 출력하고,
실패하면 다음에 무엇을 하면 되는지 알려주고 멈춘다. 아래 수동 절차는 **이 스크립트가
실패했을 때 어디를 봐야 하는지** 알기 위한 것이다.

### 1. 데이터 · 서버

- [ ] **데이터 존재 확인** — 없으면 라우팅이 전부 실패한다. 가장 먼저 본다.
  ```bash
  python3 -c "from voisso.data import load_departments as f; d=f(); print('부서', len(d['departments']), '| 수집', d['meta']['fetched_at'])"
  ```
  없으면 → `python3 scripts/scrape_gb_departments.py` (약 35초, 네트워크 필요)
- [ ] **라우팅 동작 확인** — 데모에 쓸 그 문장으로 미리 돌려본다.
  ```bash
  python3 -c "from voisso.routing import route; r=route('비가 오면 집앞 도로에 물이 안 빠져가 큰일이라예'); print(r['matches'][0]['full_name'], '|', r['matches'][0]['evidence'])"
  ```
- [ ] **MCP 셀프테스트 통과** — `python3 -m mcp_server.selftest`
      마지막 줄이 `N/N 통과` 여야 한다. **실패 항목이 있으면 그 화면은 찍지 마라.**
      대신 Claude Desktop 실사용 컷으로 5단계를 대체한다.
- [ ] `[예정]` **API 서버 기동** — `server/` 완성 시. `pip install -r requirements.txt` 후 기동,
      `http://localhost:8000` 응답 확인. **미완성이면 통화 UI를 목 모드로 간다.**
- [ ] **전화번호 매핑 확인** — `data/private/phone_map.json` 이 있으면 실번호, 없으면 대표번호
      `1522-0120` 로 표시된다. **영상에 실제 공무원 번호가 잡히지 않게** 할 거면 일부러 비워도 된다.

### 2. 브라우저 · 마이크

- [ ] **Chrome 사용** (필수). 통화 UI는 `getUserMedia` + `MediaRecorder` 로 마이크를 잡는다.
      Safari는 코덱·권한 동작이 달라 당일 변수를 만든다.
- [ ] **`file://` 로 열지 마라.** 마이크는 보안 컨텍스트를 요구한다. 반드시 로컬 서버로 연다.
  ```bash
  python3 -m http.server 8080      # 저장소 루트에서
  # → http://localhost:8080/web/call/
  ```
- [ ] **마이크 권한 미리 허용** — 촬영 중 권한 팝업이 뜨면 그 컷은 버린다. 사전에 한 번 눌러 둔다.
- [ ] **입력 장치 확인** — 시스템 설정에서 사용할 마이크가 선택돼 있는지. 외장 마이크 권장.
- [ ] **알림 끄기** — macOS 방해금지 모드. 슬랙·메일 배너가 뜨면 다시 찍어야 한다.

### 3. 화면

- [ ] **해상도 1920×1080 고정.** 심사 영상은 대개 축소 재생된다. 그 이상은 글씨가 작아진다.
- [ ] **테마: 라이트 모드로 통일한다.**
      통화 UI와 대시보드 **둘 다 `prefers-color-scheme` 자동 전환**을 지원한다.
      시스템 테마가 바뀌면 두 화면 톤이 어긋난다. **촬영 전 시스템을 라이트로 고정**하라.
      (어두운 배경을 원하면 둘 다 다크로 — **섞지만 않으면 된다.**)
- [ ] **브라우저 확대 125~150%** — 어르신 대상 서비스인데 글씨가 작으면 설득력이 떨어진다.
- [ ] **북마크바·확장프로그램 아이콘 숨기기.** 전체화면(⌃⌘F) 권장.
- [ ] **대시보드를 두 번째 탭/창에 미리 열어 둔다.** 4단계 분할 화면 전환이 매끄러워진다.
- [ ] **개인정보 점검** — 화면에 실제 전화번호, 개인 계정, 사내 URL이 잡히지 않는지 **녹화 전 한 번 훑는다.**

### 4. 녹화 직전 최종 리허설

- [ ] 0단계부터 5단계까지 **한 번 끊김 없이** 돌려본다.
- [ ] 총 길이를 재고 2분 30초를 넘으면 **2단계 대화 턴을 줄인다** (여기가 가장 늘어나는 구간).
- [ ] 백업 녹화본이 있는지 확인 (아래 실패 대비책).

## 실패 대비책

**목적: 발표장에서 당황하지 않는 것.** 각 상황의 폴백을 미리 정해 두고, 전환에 10초 이상 쓰지 않는다.

| 상황 | 증상 | 폴백 | 전환 방법 |
|---|---|---|---|
| **네트워크 끊김** | 스크레이퍼·API 전부 실패 | **이미 수집된 로컬 데이터로 진행.** 라우팅과 MCP는 네트워크가 필요 없다 — 전부 로컬에서 돈다. | 아무것도 안 해도 된다. 단 **당일 `--refresh` 를 돌리지 마라.** 있는 데이터로 간다. |
| **API 서버 다운** | 통화 화면이 "서버 응답 없음" | **목 모드로 즉시 전환.** 전 과정이 그대로 시연된다. | 주소 끝에 `?mock=1` 을 붙인다 → `http://localhost:8080/web/call/?mock=1` |
| **마이크 불통 / 권한 거부** | 녹음 버튼이 안 먹음 | **텍스트 입력 모드.** 같은 문장을 타이핑한다. 정규화·라우팅·민원카드는 동일하게 동작한다. | 화면 하단 텍스트 입력창 사용. 내레이션에서 "음성 대신 텍스트로 보여드리겠습니다" 한마디만 넣는다. |
| **타입캐스트 한도 초과** | 음성 응답이 안 나옴 | **텍스트 모드.** `VOISO_TTS_PROVIDER=none` 이면 화면에 텍스트만 뜬다. 대본의 메시지는 하나도 안 잃는다. | `.env` 에서 `VOISO_TTS_PROVIDER=none` 으로 바꾸고 서버 재기동. |
| **STT가 엉뚱하게 받아씀** | 정규화 전 문장이 이상함 | **오히려 기회다.** 1단계가 증명하려는 게 정확히 그 문제다. 당황하지 말고 정규화 결과를 가리켜라. | 내레이션: "보시는 것처럼 음성인식은 사투리를 놓칩니다. 저희가 푸는 게 이 지점입니다." |
| **전부 실패** | 노트북·프로젝터 문제 | **미리 녹화한 영상 재생.** | 촬영본을 **로컬 파일로** 노트북에 둔다. 클라우드 링크만 믿지 마라. |
