# Voisso MCP 서버 — 시연 대본

> **한 줄 메시지**
> 경상북도청 96개 부서의 사무분장은 사람이 눈으로 읽는 HTML로만 존재했다.
> 우리는 그걸 **어떤 AI 에이전트든 질의할 수 있는 MCP 서버**로 만들었다.
> 우리 통화 서비스 없이도 이 서버는 그 자체로 쓸모가 있다.

시연 전 확인: `python3 -m mcp_server --check` → `데이터 OK — 실데이터 / 96개 부서`

---

## 0. 시연 전 세팅 (2분)

### A. 실데이터로 시연 (권장)

```bash
python3 scripts/scrape_gb_departments.py    # 최초 1회
python3 -m mcp_server --check               # "데이터 OK — 실데이터 / 96개 부서"
```

### B. 데이터 없이 시연 — 합성 샘플

크롤링할 시간이 없거나 현장 네트워크가 막혔을 때. 가상 부서 9개로 같은 흐름을 보여준다.

```bash
VOISSO_DATA_FILE=mcp_server/fixtures/sample_departments.json python3 -m mcp_server
```

Claude Desktop 설정에도 같은 환경변수를 넣으면 된다.

```json
"env": {
  "PYTHONPATH": "/absolute/path/to/junctionX",
  "VOISSO_DATA_FILE": "/absolute/path/to/junctionX/mcp_server/fixtures/sample_departments.json"
}
```

샘플은 `테스트국 가상수도과`, `예시국 가상재난과` 처럼 **명백히 가상**이라 실제 도청
부서와 헷갈릴 일이 없다. 서버가 기동 시 stderr 로 합성 샘플임을 알린다.
질의는 아래와 동일하게 동작하며, 답만 가상 부서로 나온다.

### C. Claude Desktop 연결 (검증 완료)

`~/Library/Application Support/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "voisso-gb": {
      "command": "python3",
      "args": ["-m", "mcp_server"],
      "env": {
        "PYTHONPATH": "/absolute/path/to/junctionX",
        "VOISSO_DATA_DIR": "/absolute/path/to/junctionX/data"
      }
    }
  }
}
```

앱을 완전히 종료 후 재시작한다. 연결 확인은 로그로 한다.

```bash
grep "connected successfully" ~/Library/Logs/Claude/mcp.log
tail -5 ~/Library/Logs/Claude/mcp-server-voisso-gb.log
#   → [voisso-gb] 데이터 96개 부서 로드 (source=voisso.data.load_departments())
```

`python3` 를 못 찾는다는 오류가 나면 절대경로를 쓴다 (`which python3` 결과).
pyenv·conda 환경이면 이쪽이 안전하다.

**응답 속도** — 서버 기동+initialize 0.4초, 첫 질의 0.07초(색인 구축 포함),
이후 질의 1~5밀리초. 시연 중 기다리는 구간이 없다.

각 응답은 실제 `find_department` 출력이다 (실데이터 96개 부서 기준).

> 도청이 안 하는 일을 도청 부서에 보내면 민원인이 두 번 전화하게 된다.

## 2. "왜 이 답을 믿을 수 있나" — 설계상의 근거

시연 중 심사위원이 물으면 이 순서로 답한다.

### (1) 모든 응답에 근거 원문이 붙는다

`evidence` 는 **경북도청 홈페이지에 공개된 담당업무 원문 그대로**다. 요약도 생성도 아니다.
비어 있을 수 없고(셀프테스트가 검사한다), 대시보드와 민원카드에 그대로 실린다.
담당자는 "AI가 왜 나한테 보냈나"를 근거 문장 하나로 확인한다.

`duty` / `position` / `phone_token` 은 **그 근거를 쓴 바로 그 담당자**의 값이다.
배정 사유와 연결되는 사람이 어긋나면 근거의 의미가 없기 때문이다.

### (2) 구어 표현과 행정 용어 사이에 사람이 만든 다리가 있다

`voisso/routing/concepts.py` — **민원 개념 사전 56개.** 우리가 직접 작성한 창작물이고
어떤 공공데이터에서도 파생되지 않았다.

```
"물이 안 빠진다 / 고인다 / 역류한다"  ->  하수도 · 하수관로 · 배수 · 우수 · 준설
"농로가 무너졌다 / 떠내려갔다"        ->  농업생산기반 · 농업기반 · 농어촌 · 복구
"쓰레기를 몰래 버린다"                ->  폐기물 · 자원순환 · 투기 · 지도점검
"가로등이 안 들어온다"                ->  (시군 소관 — 부서 배정 안 함)
```

각 개념에는 **관할**(도청 / 도·시군 공동 / 시군)이 붙어 있다.

**P5 방언 사전과 역할이 다르다.** P5는 *사투리 표기 → 표준어 표기*를 한다
(수채구영→하수구, 맥히→막히, 골묵→골목). 개념 사전은 *표준어 구어체 → 행정 용어*다.
"마당에 물이 찬다"는 사투리가 아니라 그냥 구어체라서 정규화해도 그대로다 — 이건 개념 사전 몫이다.
STT 원문을 정규화 없이 바로 라우팅하는 경로가 있어 값이 큰 사투리 표기 몇 개만 안전망으로 겹쳐 둔다.

**표현이 달라도 결과가 같다** — 이게 이 엔진의 품질 기준이다.
회귀 테스트에 도메인별 표현 변형 그룹 13개가 들어 있고, 한 그룹의 모든 문장이
같은 부서로 가야 통과한다.

```
배수    비만 오면 마당에 물이 찬다 / 빗물이 안 내려가요 / 맨홀에서 물이 역류합니다
        지하실에 물이 차올라요 / 집 앞 도랑을 좀 쳐 주세요   → 전부 맑은물정책과
도로    도로가 파여서 덜컹거려요 / 길에 구멍이 났어요 / 길이 울퉁불퉁해서…
                                                    → 전부 도로철도과
폐기물  쓰레기를 아무데나 버려요 / 길가에 쓰레기가 쌓였습니다 / 태우는 냄새가…
                                                    → 전부 환경관리과
교통    버스가 하루에 두 번밖에 안 와요 / 막차가 너무 일찍 끊깁니다 → 전부 교통정책과
가로등  가로등이 안 들어와요 / 밤에 골목이 캄캄해요 / 동네가 어두워서…
                                                    → 전부 시군 안내
```

### (3) 확신이 없으면 확신 없다고 말한다

`confident: false` 는 네 가지 경우에 나온다.

| 조건 | 의미 |
|---|---|
| 1순위 점수 < 0.48 | 어느 부서도 충분히 안 맞는다 |
| 1·2순위 격차 < 0.10 | 두 부서가 비등하다 — 사람이 골라야 한다 |
| `grounded: false` | 민원인이 쓴 단어가 사무분장 원문에 아예 없다 |
| 맥락 부족 | 같은 말이 맥락에 따라 소관이 갈린다 |

**맥락에 따라 소관이 갈리는 민원.** "집이 물에 잠겼어요"는 상시 배수 불량일 수도,
호우 재난 피해일 수도 있다. 전자는 하수도(맑은물정책과), 후자는 자연재난과 소관이다.
개념 사전이 이런 개념에 `needs_context` 를 달아 두고, 원인을 가리는 신호
(상시·반복 / 태풍·호우)가 함께 잡히지 않으면 **단정하지 않고 양쪽 후보를 함께** 낸다.
`next_action.type` 은 `need_context` 가 되어 무엇을 더 물어야 하는지 알려준다.

```
"집 앞에 물이 안 빠지고 자꾸 고여서"   → 맑은물정책과 0.73  단독 배정
"지난 호우로 마을이 침수됐습니다"       → 자연재난과   0.92  단독 배정
"집이 물에 잠겼어요"                  → 두 부서를 함께 제시, 단정 안 함
```

점수 임계값 0.48은 실데이터에서 측정해 잡았다.

```
정상 민원 질의 10건        : 0.653 ~ 1.000
도청 소관이 아닌 질의 5건   : 0.000 ~ 0.312
   ("심해 잠수정 도색", "화성 이주 신청", "강아지가 아픈데", "빙하 탐사선 견인")
```

두 분포 사이가 비어 있고, 그 가운데를 임계값으로 잡았다.
**틀린 부서로 확신에 차 보내는 것보다 "확실하지 않다"고 말하는 편이 담당자에게 낫다** —
공공 서비스에서 오배정은 민원인이 두 번 전화하게 만든다.

### (4) 도청이 안 하는 일은 시군으로 넘긴다

가로등·보안등, 주민등록 제증명, 생활쓰레기 수거, 주차 단속, 유기동물 구조 —
전부 시군 소관이라 도청 사무분장에 아예 없다. 이런 질의는 `municipal_referral` 로
분류해 **부서를 하나도 배정하지 않고** 시군 민원실로 안내한다.

도로 파손·신호등·무단투기처럼 도와 시군이 나눠 맡는 일은 부서를 배정하되
`jurisdiction_note` 로 관할이 갈린다는 사실을 함께 알린다.

### (5) 모든 응답에 "다음 행동"이 붙는다

"모르겠습니다"로 끝나면 어르신에게는 아무 도움이 안 된다. 어떤 분기로 가든
`next_action` 이 다음에 뭘 해야 하는지 말해 준다.

| 상황 | `next_action.type` | 내용 |
|---|---|---|
| 단독 배정 | `call_department` | 해당 부서·직위로 연결. 근거를 함께 전달 |
| 후보 제시 | `confirm_candidates` | 후보 N곳을 근거와 함께 보여주고 담당자가 선택 |
| 시군 소관 | `municipal_office` | 시·군청 민원실 (문장에서 시군을 찾으면 이름까지) |
| 관할 밖 | `other_jurisdiction` | 군위군 → 대구광역시 (2023년 편입) |
| 매칭 0건 | `province_main` | 경상북도청 대표번호 1522-0120 |

시·군 감지는 `voisso/routing/regions.py` 가 한다. 경상북도 **22개 시·군**
(군위군은 2023년 7월 대구광역시 편입으로 제외). 지명이 일상어와 겹치는 곳
(영양군/"영양 상태", 고령군/"고령자", 상주시/"상주")은 `시`·`군` 접미사가
있어야 인정하도록 해서 오안내를 막았다.

**시·군 민원실 직통번호는 일부러 넣지 않았다.** 확인 못 한 번호를 자신 있게
안내하는 것은 대표번호로 넘기는 것보다 나쁘고(계약서 3절 — 가짜 번호 금지),
번호는 바뀐다. 나중에 확인된 번호를 채우면 `regions.py` 의 `phone` 필드에
넣는 즉시 안내 문구가 바뀐다.

### (6) 근거를 못 대면 아예 답하지 않는다

질의 6처럼 후보가 하나도 임계선을 못 넘으면 빈 목록과 대표번호(1522-0120)를 돌려준다.
없는 부서를 지어내지 않는다.

### (7) 전화번호는 토큰으로만 나간다

응답에는 `PHONE_1226` 같은 토큰만 있다. 실번호는 gitignore 대상인
`data/private/phone_map.json` 에서만 풀리고, 매핑이 없으면 대표번호로 폴백한다.
도청 원문 사무분장에는 내선번호가 본문에 섞인 항목이 80건 있는데
(`행사, 의전 [행정☎ (소방) 880-6110]`), 색인 단계에서 제거하므로
근거 원문으로도 새지 않는다.

### (8) 재현 가능하다

```bash
python3 -m mcp_server.verify_connection # MCP 실연결 검증 (설정·로그·프로토콜 왕복)
./scripts/test.sh                       # 통합 러너 (회귀가 여기 물려 있다)
python3 -m mcp_server.regression        # 라우팅 회귀 132케이스, 통과율 출력
python3 -m mcp_server.regression --all  # 케이스별 근거까지
python3 -m mcp_server.selftest -v --real-data   # 69개 항목 (회귀 포함)
python3 -m mcp_server.selftest                  # 데이터 없이 합성 샘플로도 통과
```

회귀 테스트에는 실제 음성 왕복 테스트에서 나온 문장, P5의 `demo_lines.md` 대사
(사투리 원문 / STT 예측 / 정규화 후 3가지 입력을 각각 채점), 도청 소관이 아닌
질의가 들어 있다. **정답이 없는 질의에 부서를 배정하면 실패로 친다.**

```
normalize_dialect "하수구가 막혔어예" → "하수구가 막혔어요"   (voisso.dialect 연동)
to_dialect        "막혔습니다"        → "막혔습니더"
submit_complaint  민원카드            → data/complaints/0001.json 저장
```
