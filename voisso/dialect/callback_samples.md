# 진행 안내 콜백 — 브리핑 사투리 변환 검수

> 이 파일은 `python -m voisso.dialect --callback` 로 **생성된다.**
> 손으로 고치지 말고 사전이나 표본을 고친 뒤 다시 생성하라.

계약서 5-C. 담당자가 진행 상황을 표준어로 쓰면 **AI 가 어르신에게 전화를 걸어 사투리로 읽어 준다.**

> ⚠️ **실제 전화망(PSTN) 연동은 H3 다.** 지금은 브라우저에서 수신 화면을 띄우는 시뮬레이션이다.

## P6 이 부를 함수

```python
from voisso.dialect import briefing_to_dialect, callback_question

dialect = briefing_to_dialect(briefing_text)   # 어르신이 들을 브리핑
# standard 는 원문 그대로 저장한다 (계약서 5-C: 둘 다 보관)

verdict = callback_question(caller_text)       # 추가 질문 처리
if verdict["verdict"] == "relay":
    say(verdict["suggested_reply"])          # AI 가 답하지 않는다
    relay_to_officer(caller_text)
```

### 핸드오프(5-B)와 한 단계 다르다

**브리핑은 소리 내어 읽는다.** 공문은 "현장 확인 완료." 처럼 명사로 끝나는데, 그대로 읽으면 전화가 아니라 공문 낭독이 된다. 그래서 브리핑 경로에서만 문장 종결형으로 먼저 편다.

| 입력 | `officer_to_dialect` (5-B 채팅) | `briefing_to_dialect` (5-C 낭독) |
|---|---|---|
| 현장 확인 완료. | 현장 확인 완료. (그대로) | 현장 확인 다 했습니더. |

## 추가 질문 처리 — 절대 규칙

**AI 는 담당자가 쓴 내용만 전달한다.** "언제 됩니꺼?" 에 브리핑에 없는 답을 지어내면 그것은 **행정 약속**이 된다. 공공기관이 이걸 보면 채택하지 않는다.

그래서 질문을 두 갈래로 가른다. **애매하면 넘기는 쪽이다.**

| 어르신 질문 | 판정 | 근거 |
|---|---|---|
| 그라믄 언제 됩니꺼? | 🚫 담당자에게 넘김 | `언제`, `언제 됩` |
| 얼매나 걸리노? | 🚫 담당자에게 넘김 | `얼마나 걸리`, `얼매나 걸리` |
| 돈은 얼마나 드노? | 🚫 담당자에게 넘김 | `얼마` |
| 진짜 되는 거 맞나예? | 🚫 담당자에게 넘김 | `진짜 되` |
| 누가 오노? | 🚫 담당자에게 넘김 | `누가 오` |
| 접수번호가 몇 번이라예? | ✅ 답해도 됨 | `접수번호`, `번호가 몇` |
| 어느 부서에서 맡아 하노? | ✅ 답해도 됨 | `어느 부서` |
| 누가 담당이라예? | ✅ 답해도 됨 | `누가 담당` |
| 알겠심더. 고맙습니더. | 🚫 담당자에게 넘김 | — |

### 넘길 때 쓰는 문장

- 담당자에게 여쭤보고 연락드리겠습니더.
- 담당자에게 그대로 전해 드리겠습니더.
- 제가 말씀드릴 수 없는 부분이라 확인해서 알려 드리겠습니더.

일정·가능 여부를 단정하는 말이 들어가지 않는지 테스트로 고정해 뒀다 (`tests/test_callback.py`).
