# 사전 출처와 라이선스

> Voisso(보이소) 경북 방언 레이어 — `lexicon.json` 에 실린 모든 항목의 출처와 재배포 조건.
> 관련: 프로젝트 전체 방침은 [`docs/DATA_LICENSE.md`](../../docs/DATA_LICENSE.md) 참조.

## 0. 먼저 — 우리가 하지 않은 것

**방언 음향 모델을 학습시키지 않았다.** 48시간 해커톤에서 음향 모델 파인튜닝은
불가능하고, 시도하지도 않았다. "사투리 TTS를 학습했다"는 주장은 이 저장소 어디에도 없다.

이 레이어가 하는 일은 두 가지다.

1. 출처가 기록된 어휘·어미 사전에 기반한 **결정론적 문자열 변환** (`core.py`)
2. `VOISSO_DIALECT_LLM=1` 일 때만 켜지는 **선택적** LLM 다듬기 (`llm.py`, 기본 꺼짐)

품질의 근거는 코퍼스 규모가 아니라 **왕복 보존 검사**다.
`python -m voisso.dialect --roundtrip-report` 로 언제든 재현할 수 있다.

## 1. AI Hub 방언 코퍼스 — 검토했고, **의도적으로 제외했다**

| 항목 | 내용 |
|---|---|
| 대상 | [한국어 방언 발화(경상도), `dataSetSn=119`](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=119) |
| 이 저장소에 포함된 항목 수 | **0개** |
| 근거 | [AI-Hub 이용정책](https://www.aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105) 제5항 |

이용정책 제5항 원문:

> "제공 받은 AI데이터 등을 수행기관 등과 한국지능정보사회진흥원의 승인을 받지 않은
> 다른 법인, 단체 또는 개인에게 **열람하게 하거나 제공, 양도, 대여, 판매하여서는 안됩니다.**"

**공개 GitHub 저장소에 올리는 행위가 정확히 이 조항에 해당한다.** 이 프로젝트는
공개 저장소 + 오픈소스 라이선스가 참가 필수 조건이므로, AI Hub에서 추출한
어휘쌍을 커밋하면 두 규정 중 하나는 반드시 위반한다. 그래서 넣지 않았다.

또한 저장소 라이선스는 MIT다. MIT는 재배포·상업적 이용을 무제한 허용하는데,
우리에게는 AI Hub 데이터에 대해 그 권리를 제3자에게 넘길 권한이 없다.

### 접근 가능성도 확인했다 (다운로드 시도 없음)

지시에 따라 "샘플 데이터나 부분 다운로드로 텍스트 대응쌍만" 확보 가능한지 먼저 확인했다.

| 확인 항목 | 결과 | 근거 |
|---|---|---|
| 로그인 없는 샘플 데이터 | **없음** | 상세 페이지 HTML에 `smpleFileSn=<null>`. "2022-10-17 샘플데이터 개방" 이력 문구만 있고 실제 등록된 샘플 파일이 없다 |
| 텍스트만 부분 선택 다운로드 | **옵션 없음** | 파일 목록이 "API 다운로드" 단일 경로. 로그인 없이 받을 수 있는 것은 데이터 설명서/구축활용가이드 PDF뿐 |
| 다운로드 조건 | 회원가입 + **승인 대기** + 내국인 한정 | "데이터셋 다운로드 승인이 완료 된 후 API 다운로드 서비스를 이용", "내국인만 데이터 신청이 가능합니다" |
| 규모 | 음성 3,000시간 | [`docs/CONTRACT.md`](../../docs/CONTRACT.md) §6이 금지한 대용량 통짜 다운로드에 해당 |

**결론: 디스크를 쓰는 다운로드를 한 번도 실행하지 않았다.**

### AI Hub를 쓰고 싶은 이용자에게

데이터는 **각자 자기 계정으로 직접 받아야 한다.** 우리가 대신 배포할 수 없다.

1. [AI Hub](https://www.aihub.or.kr) 회원가입 (내국인)
2. [dataSetSn=119](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=119) 에서 데이터 신청 → 승인 대기
3. 승인 후 API 다운로드. 필요한 것은 **라벨링데이터(텍스트) 쪽 방언-표준어 대응쌍**뿐이므로,
   원천데이터(음성)를 통째로 받을 필요는 없다
4. 받은 대응쌍을 `lexicon.json` 형식으로 병합할 때는 `source` 를 반드시 **`aihub:119`** 로 적는다

`source` 접두사를 지키면 언제든 다시 분리할 수 있다:

```bash
# 재배포 가능한 항목만 남긴 사전 생성
python -m voisso.dialect.tools.filter_lexicon --exclude-source-prefix aihub: -o lexicon.public.json
```

그리고 `tests/test_convert.py` 의 `LicenseGuardTest.test_no_restricted_sources` 가
`aihub:` 항목이 섞인 사전을 **테스트 실패로 잡는다.** 실수로 커밋되는 것을 막는 장치다.

## 2. 실제로 쓴 출처

`python -m voisso.dialect.tools.filter_lexicon --stats` 로 언제든 최신 수치를 볼 수 있다.

| 접두사 | 출처 | 라이선스 | 재배포 |
|---|---|---|---|
| `wikipedia:동남_방언` | 위키백과 [「동남 방언」](https://ko.wikipedia.org/wiki/동남_방언) | CC BY-SA 4.0 | ✅ |
| `curated:어미규칙` | 직접 정리한 어미·문법 변환 규칙 | 이 저장소 라이선스 | ✅ |
| `curated:민원도메인` | 직접 정리한 민원 도메인 어휘 | 이 저장소 라이선스 | ✅ |
| `curated:일반어휘` | 직접 정리한 고빈도 생활 어휘 | 이 저장소 라이선스 | ✅ |
| `nikl:*` | 국립국어원 (우리말샘 / 표준국어대사전) | CC BY-SA 2.0 KR | ✅ (미사용 — 아래 참조) |
| `aihub:*` | AI Hub | **재배포 불가** | ❌ **0개** |

### `wikipedia:동남_방언` — 어미 체계의 1차 근거

종결어미 체계를 이 문서에서 확인했다. 특히 다음 항목들이 규칙의 근거다.

- 합쇼체 `-ㅁ니더/-심니더`, 해요체 상당 `-예` ("여기 있어예")
- 의문형의 **판정/의문사 구분** — 체언 `-가`/`-고`, 용언 `-나`/`-노`
  (예: "집에 가나?" vs "어데 가노?")
- 명령 `-(으)시이소`, 청유 `-(으)입시더`
- 인용형 `-카다` (표준어 `-고 하다`)
- 어휘 대응 일부: 새비(새우), 무시(무), 머심아(사내아이), 가시나(계집아이),
  아부지(아버지), 어무이(어머니)

CC BY-SA 4.0이므로 **동일조건변경허락**이 붙는다. 이 조건 때문에 `lexicon.json` 은
저장소 코드(MIT)와 **분리해서** CC BY-SA 4.0으로 배포한다. 아래 §4 참조.

### `curated:*` — 직접 작성

규칙 대부분과 어휘 대부분이 여기 해당한다. 공개된 방언 문헌과 일반적으로 알려진
경상도 어휘 지식을 바탕으로 직접 정리했고, **각 항목이 민원 통화 맥락에서
자연스러운지를 기준으로 취사선택했다.** 다음은 의도적으로 **뺀** 것들이다.

- `억수로`, `-구마`, `-카이`, `가시나`, `머시마` → `to_dialect` 에서 제외.
  어르신 대상 공공 서비스에서 희화화된 사투리는 역효과다. (`normalize` 방향으로는
  알아들어야 하므로 사전에는 남아 있다)
- `질`(길), `마치`(망치), `지름`(기름), `가물`(가뭄), `갈비`(솔가리), `어름`(얼음)
  → 표준어와 충돌해 오변환을 만든다. "질문"→"길문", "마치"(부사)→"망치" 같은 사고가
  실제로 난다. **양보다 정밀도를 택해 통째로 뺐다.**
- 방언형과 표준형이 **같은 낱말** (돈, 신청, 접수, 서류, 논, 밭, 이장 …)
  → 변환에 아무 일도 하지 않으면서 사전 규모만 부풀리는 패딩이다. 넣지 않는다.
  `tests/test_convert.py::test_no_identity_pairs` 가 이를 강제한다.

그래서 금전(3)·신청·서류(2) 같은 도메인은 항목 수가 적다. **어휘가 부족해서가 아니라
그 도메인의 민원 어휘 상당수가 사투리에서도 같은 낱말이기 때문이다.** 숫자를 채우려고
같은 말을 넣지 않았다.

### `nikl:*` — 준비만 해 둔 경로 (현재 0개)

[우리말샘 오픈 API](https://opendict.korean.go.kr/service/openApiInfo) 는
`region` 파라미터로 경북 방언 표제어를 조회할 수 있고, 라이선스가 CC BY-SA 2.0 KR이라
재배포에 문제가 없다. 다만 **인증키 발급이 필요해 이번 범위에서는 쓰지 않았다.**

> **받지도 않은 항목에 `nikl:` 출처를 붙이지 않았다.** 출처 조작은 이 프로젝트에서
> 가장 큰 하자다. 이 접두사는 실제로 API로 받아온 항목에만, `target_code` 와 함께 붙인다.

키를 확보한 이용자는 `VOISSO_OPENDICT_KEY` 환경변수를 설정한 뒤 우리말샘 API로
사전을 증강할 수 있다. 우리말샘은 단어 단위 조회라 수백 KB 수준으로 가볍다.

## 3. 항목별 출처 확인 방법

모든 항목이 `source` 필드를 가진다. 빈 값은 테스트가 잡는다
(`test_convert.py::test_every_item_has_a_source`).

```bash
# 특정 낱말의 출처 확인
python -c "import json;print([e for e in json.load(open('voisso/dialect/lexicon.json'))['entries'] if e['dialect']=='차부'])"

# 출처별 집계
python -m voisso.dialect.tools.filter_lexicon --stats
```

## 4. 이 디렉터리의 라이선스

| 대상 | 라이선스 |
|---|---|
| 코드 (`*.py`) | 저장소 루트 [`LICENSE`](../../LICENSE) — MIT |
| **데이터 (`lexicon.json`)** | **CC BY-SA 4.0** |

`lexicon.json` 이 CC BY-SA인 이유는 위키백과(CC BY-SA 4.0) 유래 항목이 포함되어
동일조건변경허락 조건이 전파되기 때문이다. 이 사전을 가져다 쓰는 쪽은
**출처를 표시하고 동일 조건으로 배포**해야 한다.

출처 표시 문구 예:

```
경북 방언 사전: Voisso(보이소) 프로젝트, CC BY-SA 4.0.
일부 항목은 위키백과 「동남 방언」(CC BY-SA 4.0)에 근거함.
```
