# Voisso 민원 담당자 대시보드 (`web/dashboard/`)

경상북도청 민원 담당 공무원이 **AI가 접수·배정한 민원카드를 확인하고, 배정 근거를 검증하고,
필요하면 즉시 재배정**하는 실무 화면이다.

설계 원칙 하나: **근거 없는 배정은 공공기관에서 쓰이지 않는다.**
그래서 모든 민원카드에서 `assigned.evidence`(경상북도청 사무분장 담당업무 원문)를
상세 화면 최상단의 인용 블록으로 크게 노출한다.

## 실행

빌드 스텝도, 의존성도, `node_modules`도 없다. 둘 중 아무 방법이나 쓰면 된다.

```bash
# 1) 파일을 그냥 연다 (샘플 데이터로 동작)
open web/dashboard/index.html          # macOS
xdg-open web/dashboard/index.html      # Linux

# 2) 정적 서버로 연다 (권장 — 실제 API 자동 연결)
python3 -m http.server 8765 --directory web/dashboard
# -> http://localhost:8765/
```

## 데이터 출처 — 자동 전환

`app.js` 는 기동 시 계약서 5절의 API를 순서대로 탐색해 처음 응답하는 곳에 붙는다.

1. `?api=` 쿼리로 지정한 주소 (예: `index.html?api=http://localhost:8000`)
2. 현재 오리진 (`server/` 가 이 폴더를 함께 서빙하는 경우 — 운영 기본값)
3. `http://localhost:8000`, `http://127.0.0.1:8000`

셋 다 실패하면 `mock-data.js` 의 샘플 민원 6건으로 폴백하고, 우상단 뱃지가
`● 샘플 데이터`(주황)로 바뀐다. 실제 서버에 붙으면 `● 실시간 연결됨`(초록)이 된다.
**샘플에서 실서버로 넘어갈 때 코드 수정은 필요 없다.**

소비하는 엔드포인트:

| 메서드 | 경로 | 용도 |
|---|---|---|
| GET | `/api/complaints` | 목록·통계·필터 |
| GET | `/api/complaints/{id}` | 카드 선택 시 상세 재조회 |

> **P6 참고:** 대시보드를 서버와 다른 포트에서 열면 브라우저 CORS가 걸린다.
> `server/` 가 `web/dashboard/` 를 정적으로 함께 서빙하거나(권장),
> API 응답에 `Access-Control-Allow-Origin` 헤더를 넣어 주면 된다.

## 화면 구성

- **상단 현황** — 오늘 접수 / 미배정 / 재배정 / 평균 통화시간 / 부서별 분포
- **좌측 목록** — 접수번호, 시각, 통화시간, 요약, 배정 부서, 상태 뱃지 (최신순)
- **우측 상세**
  - 요약·분류·접수시각·통화시간
  - **배정 부서 + 직위 + 연락처 + 배정 근거 원문(인용 블록)**
  - 후보 부서와 매칭 점수 → `이 부서로 재배정` 한 번 클릭
  - 통화 전문 **[사투리 원문 | 표준어] 나란히 대조** (단독 보기 전환 가능)
  - 신고자 정보 (마스킹된 값만)

### 상태 판정 규칙

민원카드 스키마에는 상태 필드가 없으므로 다음 순서로 파생한다.
서버가 `status` 를 추가로 내려 주면 그 값을 우선 사용한다.

| 상태 | 조건 |
|---|---|
| 재배정 | 담당자가 이 브라우저에서 부서를 변경함 |
| 미배정 | `assigned` 가 없거나 `full_name`/`department_id` 가 비어 있음 |
| 배정완료 | 그 외 |

### 재배정 저장 위치

계약서에 배정 변경 API가 없어, 재배정은 현재 **브라우저 `localStorage`** 에만 기록한다
(원본 AI 배정은 보존되며 `↩ AI 배정으로 되돌리기` 로 복구 가능).
서버에 쓰기 API가 생기면 `app.js` 의 `reassign()` / `undoReassign()` 두 함수에서만
호출을 추가하면 된다.

## 개인정보 처리 (계약서 3절 준수)

- 담당자 전화번호는 `PHONE_xxxx` 토큰으로만 다룬다. 대시보드는 번호를 생성하지 않는다.
- 서버가 `resolve_phone()` 으로 해석한 실번호를 카드에 얹어 주면 그 값을 표시하고,
  없으면 경북도청 대표번호 **1522-0120** 으로 안내한다(`대표번호 안내` 표기).
- 신고자 정보는 `name_masked` / `phone_masked` 만 표시한다.
